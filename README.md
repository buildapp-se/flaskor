# Flaskor

Vinkällare, önskelista och barskåp för ett hushåll. Lägg in ett vin med Systembolagets artikelnummer eller länk, flytta det till källaren när det är köpt, se när det är dags att dricka.

Live (planerat): https://buildapp.se/flaskor. Dokument: [CONTEXT.md](CONTEXT.md) (produkt och modell), [GRILL-STATUS.md](GRILL-STATUS.md) (beslut), [BACKLOG.md](BACKLOG.md) (arbete), [HANDOFF.md](HANDOFF.md) (läge).
